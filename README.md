# Англійська з Іскрою

Android-застосунок для планшета: щоденний урок англійської, вогник-серія на 30 днів, лисеня Іскра, віджет на головному екрані й тест раз на місяць.

Є дві частини, які оновлюються по-різному:

| Що міняєш | Де | Як доходить до планшета |
|---|---|---|
| Слова й тест місяця | файл `www/words.json` | Сам, за хвилину після збереження, коли застосунок відкрито з інтернетом |
| Вигляд, правила, новий функціонал | решта файлів | Збирається новий APK, його встановлюють поверх старого |

Прогрес (вогники, пройдені уроки, тести) лежить на планшеті й не стирається ні від оновлення слів, ні від нового APK.

---

## Перший запуск (один раз, ~15 хвилин)

1. Зареєструйся на [github.com](https://github.com) і створи **новий порожній репозиторій**, наприклад `iskra-english`. Він має бути **Public**: застосунок читає з нього слова без пароля. У файлі немає нічого особистого, лише слова.
2. Завантаж у нього всі файли з цієї папки (разом з прихованою папкою `.github`). Найпростіше через [GitHub Desktop](https://desktop.github.com) або командами:
   ```
   git init -b main
   git add .
   git commit -m "Перша версія"
   git remote add origin https://github.com/ТВІЙ_ЛОГІН/iskra-english.git
   git push -u origin main
   ```
3. Відкрий у репозиторії вкладку **Actions**. Збірка «Збірка APK» запуститься сама й триватиме 5–10 хвилин. Якщо Actions просить дозволу, натисни «I understand my workflows, go ahead and enable them».
4. Коли збірка зелена, відкрий **Releases** (справа на головній сторінці репозиторію), там буде файл `iskra-english.apk`.
5. Завантаж його на планшет (відкрий сторінку Releases у браузері планшета) і встанови. Android попросить дозволити встановлення з цього джерела: погоджуйся.
6. Відкрий застосунок. Перший запуск працює й без інтернету, бо слова вбудовані. Потім у планшета має бути інтернет хоча б раз на місяць, щоб підтягнути нові слова.
7. Додай віджет: довге натискання на порожнє місце головного екрана, Віджети, «Англійська з Іскрою», «Вогник Іскри».

## Щомісяця: додати нові слова

1. На GitHub відкрий `www/words.json` і натисни олівець (Edit).
2. Прокрути в кінець списку `lessons` і додай нові уроки. Один урок це один рядок із 4 словами:
   ```
   {"t":"Назва уроку","w":[["🍉","watermelon","кавун"],["🍓","strawberry","полуниця"],["🍒","cherry","вишня"],["🍑","peach","персик"]]},
   ```
   Кожне слово: `["емодзі","english","українською"]`. Після кожного уроку, крім останнього, стоїть кома.
3. Натисни **Commit changes**. Перевірка слів запуститься сама. Якщо в ній червоний хрестик, відкрий її: там написано українською, де помилка. Поки помилку не виправлено, застосунок користується попередніми словами.
4. Усе. Наступного разу, коли вона відкриє застосунок з інтернетом, нові уроки з’являться самі.

**Правила, щоб нічого не зламати**
- Нові уроки додавай тільки **в кінець**. Порядок старих не міняй і старі не видаляй: пройдені уроки запам’ятовуються за номером.
- У кожному уроці 4 слова, англійські слова в межах уроку не повторюються.
- Емодзі дивись на [emojipedia.org](https://emojipedia.org). Деякі нові емодзі можуть не показатися на старому планшеті.
- Перевірити файл на своєму ПК до збереження: `node tools/validate.mjs www/words.json`.

Зараз у файлі 30 уроків, на 30 днів серії. Якщо серія триватиме довше, уроки з кінця списку закінчаться, і замість нових слів буде «Повторення» (4 випадкові слова зі старих). Тому корисно додавати нові раніше.

## Щомісяця: тест

**Автоматично.** Після 25-го числа (змінюється в `testDay`) на головному екрані з’являється картка «Тест місяця». Це 10 питань зі слів, які вона вчила цього місяця. Якщо тест не пройдено до кінця місяця, картка залишається й наступного місяця, і слів тоді беруться з минулого. Результати зберігаються в блоці «Мої тести».

**Свої слова в тест.** Хочеш додати слова, яких не було в уроках (наприклад, зі школи), впиши їх у `monthlyTests` за місяць:
```
"monthlyTests": {
  "2026-12": [["🎄","Christmas tree","ялинка"],["🎁","present","подарунок"]]
},
```
Вони потраплять у пул питань грудневого тесту разом зі словами її уроків.

Додатково в `words.json` можна змінити `testDay` (число від 1 до 28) і `goalDays` (скільки днів серії до призу).

## Нова версія застосунку

Якщо міняєш не слова, а сам застосунок (вигляд, правила), після Commit на `main` збірка запускається сама й оновлює APK в Releases. Завантаж новий `iskra-english.apk` і встанови поверх старого, прогрес збережеться. Це працює тому, що всі збірки підписані одним і тим самим ключем із `android/keystore`. Ключ лежить у репозиторії, тож **не роби його публічним для чужих проєктів** і не використовуй цей ключ для нічого іншого.

## Робота без GitHub

Можна віддавати APK без Releases: у Actions відкрий останню збірку й візьми файл зі списку Artifacts, потім передай його на планшет флешкою чи месенджером.

## Скидання прогресу

У застосунку: ⚙️ → «Стерти прогрес» (двічі натиснути).

---

## Що всередині

- `www/` вебчастина застосунку (HTML, шрифти, `words.json`)
- `android/` Android-проєкт: віджет (`IskraWidget.java`), міст між застосунком і віджетом (`IskraBridge.java`), іконка, підпис
- `.github/workflows/` збірка APK та перевірка слів
- `tools/validate.mjs` перевірка `words.json`

Технічно це веб-застосунок у Android-оболонці (Capacitor 8), а віджет повністю нативний.
